# Biblical Art Download Checklist

Add each image to `Resources/Assets.xcassets/BiblicalArt/` as an image set.
Name format: `biblical_<key>` (e.g., `biblical_good_samaritan`)

Best source for each: linked below. Download the highest resolution available,
Xcode will handle scaling. Recommended: crop to 16:9 landscape for card display.

## How to Add Images

1. Download the image from the source link
2. In Xcode, right-click `Resources/Assets.xcassets/BiblicalArt/`
3. Select "New Image Set"
4. Name it `biblical_<key>` (e.g., `biblical_good_samaritan`)
5. Drag the downloaded image into the 1x slot (or Universal)
6. Repeat for each image

**Tip**: Start with Priority 1 (Life of Jesus) — these cover the most common chat topics.
The app works perfectly without any images — gradient fallbacks look great.
